# Reference seed entries (not live listings)

These seven JSON files are **illustrative only**. Each shows what a well-known public API *could* look like if it published `/.well-known/agent-manifest.json` at its origin.

| Field | Meaning |
|--------|--------|
| `status: "unverified"` | Built from public docs/OpenAPI — **not** validated at the provider’s site |
| `publisher.group: "seed"` | Curated example in this repo, not a publisher submission |
| `submitted_via: "import"` | Generated by `npm run import-seeds`, not `POST /listings/submit` |

**They are not in production.** `https://api.agent-manifest.com/listings` reads **Railway Postgres** (real submissions and migrated listings only). Seeds stay in git for docs, PR checks, and optional static builds — not the public registry API.

Do not treat these as endorsement by Stripe, SWAPI, etc. See spec §19.4 (`verified` vs `unverified`) in [AMP `spec/v0.3.md`](https://github.com/AMProtocol/AMP/blob/main/spec/v0.3.md).
